# AI Travel Planner Macedonia

## Што е апликацијата

AI Travel Planner Macedonia е веб и мобилна (PWA) апликација за планирање патувања низ Северна Македонија, моментално за Охрид, Скопје и Битола.

Туристот внесува град, број на денови, буџет, интереси (историја, природа, плажи, храна…), темпо, превоз и подвижност. Апликацијата му прави план по денови: кои места да ги посети, по кој редослед, во колку часот и каде да руча. Местата се избираат само од проверен каталог, а редоследот се оптимизира за најмалку време на патување. Планот може да се менува со обичен текст („поевтино“, „помалку пешачење“) и да се симне како PDF.

Покрај планирањето, апликацијата служи за:

- **резервации:** сместување, бродски тури, ресторани и такси;
- **локален превоз:** градски автобуси со возен ред и изнајмување велосипеди;
- **мапа:** пекари, маркети, менувачници, трафики, банкомати и аптеки во близина (OpenStreetMap);
- **рецензии:** само од гости со завршена резервација;
- **фото-посети, печати и беџови:** се добиваат со посета на знаменитости на лице место;
- **социјален дел:** пријатели и лајкови на фотографии;
- **пристапни маршрути:** за лица со намалена подвижност и со инвалидска количка;
- **два јазика:** македонски и англиски, и инсталирање на телефон.

Ја користат три вида корисници:

| Корисник | Што прави |
|---|---|
| Турист | Прави планови, резервира и собира беџови. |
| Бизнис | Ги објавува своите услуги, цени и слободни термини и ги прифаќа барањата. |
| Администратор | Ги одобрува бизнисите и местата и го уредува каталогот. |

**Технологии:**
- backend: Django + Django REST Framework, PostgreSQL;
- frontend: React + Vite;
- мапи: Leaflet и OpenStreetMap;
- оптимизација на рути: Google OR-Tools;
- AI: опционално Claude (Anthropic).

## Стартување

### Со Docker

```bash
cp .env.example .env
docker compose up --build
```

### Локално (без Docker)

Потребни се Python 3.12 и Node.js 20+.

Backend:

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py fetch_images    # фотографии (потребен е интернет)
python manage.py runserver
```

Frontend, во друг терминал:

```bash
cd frontend
npm install
npm run dev
```

Без `DATABASE_URL` во `.env`, backend-от користи локална SQLite база.

|---|---|---|

| Бизнис | `host` | `Host12345!` |
| Администратор | `admin` | `Admin12345!` |

### Опционални поставки во `.env`

| Променлива | Што вклучува |
|---|---|
| `LLM_PROVIDER=anthropic` и `ANTHROPIC_API_KEY` | AI избор на места (без нив работи детерминистички алгоритам) |
| `OPENWEATHER_API_KEY` | временска прогноза |
| `ROUTING_PROVIDER=osrm` | реални рути по патишта наместо проценка |
